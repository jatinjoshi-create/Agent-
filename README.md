# Agent-

This project hosts the Celestial luxury showcase landing page.

## Run locally

Use the helper script to serve the page from the repository root:

```bash
./serve.sh 8000
```

Then open http://localhost:8000 in your browser to experience the full-screen hero and luxury video section.

You can stop the server with `Ctrl+C`. To use a different port, pass it as the first argument (for example, `./serve.sh 9000`).
